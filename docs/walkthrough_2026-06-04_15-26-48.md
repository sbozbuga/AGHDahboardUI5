# Walkthrough: UI5 Bootstrap, Tests, and Cache Busting Fixes

## Changes Made

### 1. Fixed OPA Test Failures (`manifest.json`)
- **What Changed:** Reverted `bundleUrl` to `bundleName: "ui5.aghd.i18n.i18n"` in the i18n model configuration.
- **Why:** `bundleUrl` was causing the translation files to return 404s when running tests because it tried to resolve paths relative to the test runner's URL instead of the component root.
- **Result:** The UI text correctly translates during testing.

### 2. Fixed JSON Parsing Errors (`index.html`)
- **What Changed:** Removed the `#v=1.0.1` fragment from `data-sap-ui-resource-roots` in `webapp/index.html`.
- **Why:** The browser was treating the resource path as a fragment, causing it to request the root HTML page instead of the actual JSON or JS modules it needed.
- **Result:** The application now correctly requests module paths without syntax errors.

### 3. Fixed Library Preload Errors and Implemented Cache Busting (`package.json`)
- **What Changed:** Modified the `build:opt` script. In addition to appending a timestamp cache-buster query parameter to `sap-ui-custom.js`, the script now appends `data-sap-ui-preload=""` to the bootstrap configuration in the built `dist/index.html`.
- **Why:** Reverting to `sap-ui-core.js` broke the self-contained build. By keeping `sap-ui-custom.js` and configuring `data-sap-ui-preload=""`, we prevent the UI5 runtime from issuing redundant requests for standard `library-preload.js` files, which are already contained within the custom bundle and otherwise trigger MIME type errors.
- **Result:** Redundant 404 and MIME type errors for library preloads are eliminated.

### 4. Resolved Version Info JSON Parsing Errors (`package.json`)
- **What Changed:** Appended `--include-task generateVersionInfo` to the `ui5 build` command.
- **Why:** During theme loading, the framework requests `sap-ui-version.json`, which is no longer generated by default in UI5 CLI v3+. Explicitly including this build task generates the file.
- **Result:** The `SyntaxError` for version info loading is fully resolved.
